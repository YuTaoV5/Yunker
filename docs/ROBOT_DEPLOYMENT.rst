实机部署与硬件适配
==================
当前不授权自动启动实机，机器人可保持断电。已有ROS2源码和旧ONNX仅作归档；新195D模型不是旧660D模型的直接替换。

结构：Jetson运行ROS2 Humble推理与串口桥接；STM32把目标与Kp/Kd通过CAN MIT帧送给电机。源码推理dt=.02即50Hz；既有被动采样关节100.224Hz、IMU99.997Hz，这是回调到达率而非端到端采样年龄。STM32腿任务约10ms重发目标，不等于电机驱动内部闭环只有100Hz；驱动内部真实频率尚未核实。

训练1kHz PD是仿真模型，不代表Jetson需要每毫秒执行神经网络，也不能证明真机PD带宽一致。上板前需无动作推理计时、端到端时间戳与p99抖动、每电机反馈新鲜度、受限单轴阶跃/扫频、负载/温升/电源压降测试。当前未证实板载卡在完整ROS负载下20ms截止时间必达。

源码DM6006/DM8006的协议力矩范围分别±12/±20Nm，与训练限幅匹配；协议量程不是连续额定输出、峰值持续时间或热能力证明。真实型号、电机配置、电流限制、减速比、回差与扭矩-转速曲线仍需核验。已存在旧策略行走也不证明新策略满足硬件能力。

部署顺序：
1. 保存现有模型、ROS工作树和服务配置，明确可恢复版本；核对固件二进制与源码。
2. 在独立ROS工作区安装依赖并colcon build；按实际设备设置串口与权限，禁止安装后自动enable服务。
3. 按新合同实现195D观测、默认角、轴序和符号；用离线录制数据检查ONNX/框架一致性与历史初始化，不连接电机输出。
4. 完成传感器时间戳、过期包拒绝、命令超时响应与受控停止。旧固件缓存目标重发且未确认watchdog，停ROS不能视为停机。
5. 全仿真验收通过后，再安排支架、现场断电人员与受限低增益实机分级验证；不得直接自由行走。

左右定义以机器人默认前进方向为准，YuTaoV5面板在背面。机械零位不得通过照片估计后永久写入。
