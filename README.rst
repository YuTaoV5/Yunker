Yunker / Tinker 双足研发与部署归档
================================
本仓库保存本次项目研究、训练、跨仿真评估和实机部署资料。参考项目源码直接包含在仓库中，不以链接代替源码。各上游许可证归各自权利人所有，本仓库不统一重新许可第三方代码。

当前状态：NOT_PASSED，禁止把训练奖励或已有旧教师模型当作新模型实机验收。
当前已核实训练版本 V10，195维观测、50Hz策略、1ms仿真步长；存在跟踪超标、后退/纯转向不执行和故障跌倒。V11仅为指令覆盖候选。

目录：
* training/isaaclab_tinker：任务、训练器、导出、双仿真评估、边界注入、既有结果与候选合同。
* robot/legged-robot-ros2：ROS2上游工作树；inspected-runtime为此前从Jetson读取的实际源码快照，两者不能混淆。
* firmware/legged-robot：STM32基线源码，尚未核验板上二进制一致。
* references：原始Tinker和OmniCtrl源码、许可证及版本来源。
* docs：服务器部署、实机部署、接口、验收和缺失清单。

首先阅读 docs/ARCHIVE_STATUS.rst。资产缺失项补齐前不是可复现安装包。不要自动启用实机服务或覆盖旧模型。
